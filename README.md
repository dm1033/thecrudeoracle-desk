# The Crude Oracle

A free oil-industry desk. Punchy. First person. No hedge language.

**Live:** [www.thecrudeoracle.com](https://www.thecrudeoracle.com)

Built for traders, operators, NOCs and investors. Public sources (EIA, IEA, OPEC, Baker Hughes, Dallas Fed). Delayed quotes labelled delayed. Not a buy ticket.

## What's on the desk

| Book | What it is |
|---|---|
| Desk | Delayed tape, prints, continent atlas, Ask the Oracle |
| Continents / Producers | Reserves, production, R/P, revenue streams, listed doors |
| Industry | Spare, two breakevens, decline, capex |
| Trade | Grades, chokes, 3-2-1 crack |
| AIS | VesselFinder expected arrivals + port calls, MarineTraffic tankers in the choke boxes |
| Invest | Watchlist mapped to barrels and cash |
| Jobs · Earn $$$ | Oil-industry search + skill transfer + [Construct CV](https://linkedinconstructioncvprofile.com/) |
| Substack | Dispatch letter + RSS at `/feed.xml` |
| Sources | Canonical register with last print and next window |

## Stack

TanStack Start · React · Tailwind v4 · Recharts · Nitro on Vercel.

```bash
npm install
npm run dev        # local desk
npm run build      # production
npm run typecheck
```

## Method

- OPEC reserves are OPEC reserves. Canada oil sands are not smuggled into the OPEC table.
- Do not mix a lifting cost with a new-well breakeven with a fiscal breakeven.
- Nameplate gap is not spare if the barrels cannot load.
- Jobs pay bands are public ranges (BLS, Rigzone, Robert Half, OneSource, ARAM Gulf), not offers.

Commentary for information only. Not investment advice. Capital at risk.
